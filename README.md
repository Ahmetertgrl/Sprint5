Canlı Site: https://sprintt5.vercel.app/

Dosya Açıklamaları:
- package.json: Proje adı, komutlar (dev, build) ve paket listesini tutar.
- vite.config.ts: Vite ayarları ve React eklentisini barındırır.
- index.html: Uygulamanın tek HTML dosyasıdır, içinde boş div#root bulunur.
- src/main.tsx: React'i başlatır ve App bileşenini root'a çizer.
- src/App.tsx: Uygulamanın ana bileşenidir, tüm sayfalar ve state'ler buradadır.
